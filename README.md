# Fixify — Pemutar Musik Android Tanpa Iklan & Stereo Studio

Repository resmi **Landing Page** dan **Rilis APK** untuk aplikasi musik Android **Fixify**.

## Unduh Aplikasi (Android APK)

Dapatkan rilis `.apk` resmi terbaru melalui halaman **[GitHub Releases](https://github.com/riantosee/fixify/releases/latest)**.

## Fitur Utama Fixify

- **Latar Belakang & Layar Mati 100% Aktif** — Audio tetap berputar lancar saat layar dikunci atau pindah aplikasi, lengkap dengan kontrol Lockscreen.
- **0 Iklan Selamanya** — Streaming audio langsung tanpa jeda iklan video.
- **Fixify Stereo Studio DSP** — Pilihan *Stereo Wide HD*, *3D Spatial Concert*, *Deep Bass Stereo*, *Crystal Vocal*, dan *Original*.
- **Komunitas Live & Playlist Bersama** — Ngobrol bareng member di `# Umum`, `# Berbagi Lagu`, `# Santai`, kirim kartu lagu yang langsung bisa diputar, dan kolaborasi playlist publik.
- **Sistem Role (`DEV` • `ADMIN` • `MEMBER`)** — Profil dengan Avatar & Banner GIF bergerak 60fps serta bingkai neon.
- **Cache Ringan & Auto-Update** — Cache API + cache audio otomatis (auto-LRU maks. 120 MB) dan deteksi pembaruan otomatis langsung dari repository ini.

## Auto-Update Manifest

Aplikasi Android Fixify secara otomatis memantau `Releases` terbaru dan berkas [`version.json`](./version.json) pada repository ini untuk memberi tahu pengguna saat versi baru tersedia.
